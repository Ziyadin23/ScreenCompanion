# Design

Use the previous [public update procedure](../../../tests/README.md#installed-updates) on the two published installers. Capture both releases' anonymous metadata and verify the downloaded files. Leave the installed GitHub feed intact.

Run the update as a standard Windows 11 x64 user. Record the starting installation, profile, updater cache and shortcuts under the exclusive lab claim. Protect existing files before starting the published beta.6 installer. Use synthetic settings with a legacy `Balanced` selection. Beta.16 should expose `Thorough` for the selected model and retain the other saved preferences.

Inspect the first download before an ordinary exit. Reopen the installed client and make the explicit restart choice. Read the running version, installation registration, both shortcut targets and settings again in a fresh process. Compare a separate final inspection with the starting state. Preserve the last verified boundary and restoration evidence for any failed attempt.
