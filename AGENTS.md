# Agent guidance

Current source and release: **SC v0.4.8**, defined in [SC.csproj](SC.csproj). Read [release status](README.md#release-status) before build or publishing work. Use SC for the product name; preserve historical repository/release URLs and legacy storage identifiers.

- Changes or reviews: read [product standards](CODING_STANDARDS.md#product).
- Release preparation or publishing: read [publishing standards](CODING_STANDARDS.md#publishing).

Keep vaults, private USB bundles, and credentials out of commits, releases, logs, screenshots, and test fixtures. Public releases contain only key-free builds; release assets also exclude recordings.
