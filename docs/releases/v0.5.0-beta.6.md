# SC v0.5.0-beta.6

Windows x64 prerelease of the Electron/TypeScript application. The latest stable
release remains [SC v0.4.14](https://github.com/Ziyadin23/ScreenCompanion/releases/tag/v0.4.14).
Visit the [project website](https://ziyadin23.github.io/screencompanion-website/).

## Downloads and setup

- `SC-Setup-v0.5.0-beta.6.exe`: per-user installer with shortcuts and
  **Settings → Updates**. Administrator rights are not required.
- `SC-v0.5.0-beta.6.exe`: portable application; replace it manually for updates.
- `SC-v0.5.0-beta.6.zip`: the same portable EXE and its original `README.txt`.
- `LICENSE.txt`, `THIRD_PARTY_NOTICES.txt` and
  `ThirdPartySources-v0.5.0-beta.6.zip`: SC's MIT license, dependency notices
  and upstream installer sources. Keep applicable notices with redistributed copies.
- `SHA256SUMS.txt`: checksums for all supplied assets except itself.

Close an older SC instance before installation. On first launch, choose your API
service and enter its key. Your provider account needs model access and any
required credits. The application includes its runtime. The executables are
unsigned; Windows may show an unknown-publisher or reputation prompt.

## Changes since beta.4

- Tightens the Direct screenshot answer contract and clarifies extraction types
  for choices, code and questions that require visual information.
- Improves panel resize and hide/restore behavior, including ending a drag when
  the panel is hidden.
- Adds Windows control and updater checks, while retaining the per-user installer,
  encrypted settings migration and selectable request pipelines.

The [user guide](../USER_GUIDE.md) describes controls, providers, privacy and
updates. Captures and typed questions are sent to the selected provider. SC keeps
no screenshot or answer history; provider retention policies apply.

## Verification and limits

- Linux and Windows verification passed **1,257 tests in 27 files**, with type
  checking, lint and production bundles. The lab suite passed **266 tests in
  11 files** on both systems. Mocked tests do not establish live model quality.
- Windows native verification passed **54 checks**; vault interoperability passed
  **8 cases / 136 legacy fixture checks**. All **37 distinct UI cases** have
  passing evidence across two runs; the full run timed out after 31 passes.
- An isolated key-free packaged preview started and closed. A separate portable
  launch reached ready and exited normally. The duplicate-launch test timed out;
  duplicate activation, remaining direct/early-close scenarios and fresh-machine
  checks remain open.
- A local beta.5 → beta.6 installed update passed **31 ordered checks**, including
  restart, settings and corrupt-download rejection. Earlier failed update attempts
  remain recorded. Delivery through the public GitHub update feed has not been
  tested for beta.6.
- Beta.6 recorder attempts failed before establishing recording exclusion. Do not
  assume SC is hidden in a recording; verify the received stream or saved output
  for your capture app. The tray icon remains visible.
- Full live AI qualification is unfinished. On the earlier beta.5 build, two
  Balanced-mode diagram cases failed extraction-type grading. Beta.6 includes a
  prompt clarification, but those cases have not been fully retested live.

These Windows results are from one Windows 11 VM. Windows 10, mixed-DPI and
other capture paths also remain open. See [verification details](../VERIFICATION.md)
for the evidence and retained failures.
