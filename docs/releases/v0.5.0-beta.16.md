# SC v0.5.0-beta.16

This Windows 11 x64 prerelease lets you ask a typed question without sharing your screen. The latest stable release is [v0.4.14](https://github.com/Ziyadin23/ScreenCompanion/releases/tag/v0.4.14).

## Download and setup

- Close any running copy of SC and run the [installer (109.8 MiB)](https://github.com/Ziyadin23/ScreenCompanion/releases/download/v0.5.0-beta.16/SC-Setup-v0.5.0-beta.16.exe). It installs for your Windows account and creates shortcuts without administrator rights.
- For a portable copy, extract the [ZIP (99.4 MiB)](https://github.com/Ziyadin23/ScreenCompanion/releases/download/v0.5.0-beta.16/SC-v0.5.0-beta.16.zip) or run the [standalone EXE](https://github.com/Ziyadin23/ScreenCompanion/releases/download/v0.5.0-beta.16/SC-v0.5.0-beta.16.exe). Close SC before replacing it.

Both editions include the runtime. The installer and portable EXE are unsigned, so Windows may show an unknown-publisher warning. On first launch, choose your API service and enter your own key. Your provider’s usage charges apply.

## Changes since beta.6

- Press **Ctrl+Enter** to open **Question**. While typing, **Enter** or **Send** sends only your text. **Ctrl+Enter** or **Send with screenshot** adds one fresh capture. **Ctrl+Alt+Space** asks about the foreground app’s monitor without typing a question.
- In **Settings → Models & API**, choose a screenshot pipeline for each answer model. **Thorough** locates and extracts the question before answering. **Direct screenshot** sends the full monitor to an image-capable answer model in one call. SC keeps no screenshot or answer history. Your provider’s retention policy applies.
- Setup and Settings fit smaller windows. A Settings save can finish while you type a question or edit a newer draft. Your active view and edits stay open.
- The unpacked Windows application is 108.4 MiB smaller than a build of the same application with the previous packaging rules.

## Windows checks and limits

Both editions opened first-run setup under a standard account on one Windows 11 x64 development VM. All 38 Windows UI tests and both additional Settings tests passed. A 1920 × 1080 Edge whole-monitor VP8 recording omitted the tested setup, answer and Settings windows. The tray icon stays visible. Check your recorder’s saved video or received stream. [Windows qualification](https://github.com/Ziyadin23/ScreenCompanion/blob/2f54d740e626b9fe5b1206786a849f2b19edb8c7/docs/VERIFICATION.md#beta16-windows-qualification-2026-11-22)

A newly created Windows account, a clean machine without developer tools, two physical displays at different scales and live answer accuracy still need testing. Windows 10 is outside the support target. Linux is available as source only. Installed copies offer **Settings → Updates**. A public GitHub update to beta.16 still needs an installed-client test.
